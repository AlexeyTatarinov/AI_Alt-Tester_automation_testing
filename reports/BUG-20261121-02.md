# BUG-20261121-02: New Game: SpawnSystem пишет предупреждение «LocationEntry that doesn't exist»

- Статус: Новый
- Проверка: SCENE-02
- Severity: S5 (Trivial)
- Priority: P3
- Воспроизводимость: 3 из 3
- Дата и время: 2026-11-21, около 10:00 (ручной запуск New Game), 10:07 (MENU прогон 1), 10:49 (MENU прогон 2)
- Компонент: другое

## Окружение
- Игра: Chop Chop, коммит 386ba0d0
- Unity: 6.3 LTS (6000.3.28f1)
- Режим: Editor Play Mode
- ОС: Windows 11
- Сцена: Beach (загрузка из MainMenu через New Game)

## Шаги воспроизведения
1. Запустить Play из MainMenu.
2. Нажать «New Game».
3. Подтвердить диалог «New game».
4. Дождаться появления PigChef в Beach.
5. Открыть Unity Console (или найти строку в Editor.log).

## Ожидаемый результат
В Console нет предупреждений о точке появления: новая игра стартует в точке по умолчанию.

## Фактический результат
При каждом старте New Game пишется `The player tried to spawn in an LocationEntry that doesn't exist, returning the default one.` (стек: `SpawnSystem:GetSpawnLocation` SpawnSystem.cs:49 <- `SpawnPlayer` :58 <- `SceneLoader:StartGameplay` :196). Игрок при этом появляется в `DefaultSpawnLocation`: расстояние до неё 0,00 м (позиция −195,58; −9,50; −376,90), то есть на геймплей предупреждение не влияет.

## Доказательства
- Скриншот: нет
- Видео: нет
- Лог Console: `Reports/evidence/logs/LocationEntry_warning_excerpt.log` (строка и стек из Editor.log); в Editor.log три таких предупреждения за сессию (строки 216400, 233259, 505485 на момент снятия); результаты набора: `Reports/evidence/logs/SCENE_run1.log`, `SCENE_run2.log`.

## Примечания
- Обход проблемы: не нужен, влияния на игру не замечено.
- Почему выбрана такая severity/priority: сообщение в логе без видимых последствий (S5); встречается при каждом New Game, по матрице S5/«часто» это P3. Предупреждение раньше упоминалось в аудите 19.11 как «кандидат в баг точки появления», но позиция игрока верная.
- Гипотеза (по чтению кода): `_pathTaken` при New Game не равен null, но `lastPathTaken` не совпадает ни с одним `LocationEntrance.EntrancePath` на Beach, поэтому берётся точка по умолчанию с предупреждением. Не проверялась.
- Похожие issues: не найдено в листе «Известные баги»
