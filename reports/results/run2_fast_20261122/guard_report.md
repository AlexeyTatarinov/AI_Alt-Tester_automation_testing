## Что показали проверки без игры
- `consoleFlags`: **не прочитано** (игра на паузе, SDK не отвечает: `NoAppConnected`/тайм-аут). Значение и то, читается ли внутренний класс `UnityEditor.LogEntries`, неизвестны.
- Классификатор на реальной паузе дал «пауза редактора» и правильную последнюю ошибку (MissingReferenceException при Space в диалоге).
- `alive()` на паузе возвращает `False` за 11 с, а не зависает (сначала зависало: исправлено потоковым тайм-аутом).
- Снимок окна и состояние процесса: Responding = True, CPU ≈ 0,05 с за 1,5 с, окно не свёрнуто, не на переднем плане.

## Блокер
Unity на паузе (кнопка Pause нажата) с ≈ 18:31. Снять паузу без человека не получается: Ctrl+Shift+P из PowerShell блокирует система безопасности, а доступ computer use к окну Unity дважды отклонён (`user_denied`) при последнем запросе. Поэтому преflight, контрольный прогон страховок (MainMenu → New Game → Forest через меню читов → диалог) и блок B не выполнены.
