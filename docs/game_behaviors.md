# Известное поведение Chop Chop (знания владельца и прогонов). Читать перед КАЖДЫМ прогоном.

Обновляется Claude (чат) после каждого прогона. Если поведение здесь описано, это НЕ баг, пока не сказано иное.

## Диалоги
- После последней реплики BardHare может показать вопрос без кнопок Yes/No. Владелец: ещё ОДИН Space показывает кнопки. Скрипт в прогоне 5 нажал Space 70 раз и кнопок не получил: метод проверки требует уточнения (паузы между нажатиями, фокус окна). Не считать это багом без подтверждения.
- Прогон 6 (пауза 1,0 с, 40 нажатий): кнопки Yes/No в диалоге BardHare НЕ появились, ожидание владельца не подтвердилось. Ждём от владельца точное описание, как он видит кнопки (в какой реплике, что нажимает).
- Esc в открытом диалоге открывает меню паузы (Pause_Screen), диалог остаётся под ним (прогон 6; в прогоне 5 считали, что Esc ничего не делает).
- Второй New Game в той же сессии Play даёт другой диалог (другая последовательность реплик), и в нём появляются исключения; на чистом запуске их нет.
- Подсказка «E» у зайца появляется не сразу: нужно подойти двумя-пятью шагами в узкую зону (≈0,8 м). После закрытия диалога подсказка может вернуться только после нескольких шагов.
- Q открывает инвентарь/действие на предмете; в диалоге Q ведёт себя особо (прогон 4, DLG-11): следующий Space после Q закрывает диалог с исключением. Q в диалоге нажимать только в рисковых шагах с чекпойнтом.
- Исключения в диалоге (ArgumentOutOfRange, MissingReference, NullReference) воспроизводятся только в сессии Play, где игра уже использовалась (повторные New Game). На чистом запуске Unity их нет (прогон 5).

## Сохранение
- save.chop хранит остаток старого сохранения до нажатия New Game. После New Game список шагов квеста обнуляется (0). Шаги квеста в save.chop до New Game не считать багом New Game.
- После диалога шаг квеста записывается в save.chop сразу (0 → 1, GUID 2187c1f1…).

## Управление и меню
- Esc открывает меню паузы «Hold on!»; в открытом диалоге Esc ничего не делает. Меню читов: клавиша C.
- Красный текст «PLACEHOLDER» после New Game виден 12+ с (CC-85, S5/P4, известно).

## Unity
- Error Pause: читать флаг LogEntries.consoleFlags (7683 = выключено, 7686 = включено). Ctrl+Shift+P в фоне не нажимать.
- Свёрнутое окно Unity останавливает игру: восстанавливать без перехвата фокуса.
