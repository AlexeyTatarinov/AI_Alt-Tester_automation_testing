## 4. Тест-кейсы

### 4.0 Принципы
1. **Сначала данные, ходьба только для подтверждения.** Объекты, свойства, сцены читаются за секунды.
2. **Один набор — один скрипт.** ИИ пишет скрипт (Python, вызывает `alttester`) в `TestAI/suites/<набор>.py` один раз; прогон — запуск скрипта, ИИ только разбирает вывод. Быстрее, повторяемо, экономит лимиты Claude.
3. **Короткие шаги.** Нажатия 0,1–0,2 с; после каждого — измерение. Короткое состояние ловить с `set-time-scale 0.2`, после — вернуть 1 (`reset-input`, `set-time-scale 1`).
4. **Три прогона, честный статус.** Пройдено / Не пройдено / **Не подтверждено** (метод не дал однозначного ответа). «Пройдено» без количественного критерия не ставится.
5. **Пассивный контроль во всех наборах:** высота игрока не ниже порога локации (провал), здоровье не падает без причины, число новых ошибок в Console = 0.
6. **Не загружать Initialization через CLI.** Старт — из MainMenu (человек: Play, при зависании Pause и снять паузу).

**Общее предусловие P0:** Unity Play из MainMenu, меню отвечает, AltTester-сервер запущен, `alttester connect`. **P1:** P0 + New Game + сцена Beach, игрок на стартовом острове.

Обозначения: «Авто» — полностью автоматически; «Авто+Ч» — нужна разовая помощь человека; «Ч» — только человек.
