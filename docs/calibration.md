# Калибровка камеры Chop Chop (CAM-00)

Ручная проверка человеком, реальная мышь, 21.11.2026. Сцена Beach, Editor Play Mode.

- Камера вращается только при зажатой правой кнопке мыши (ПКМ).
- Мышь вправо: камера поворачивается влево.
- Мышь влево: камера поворачивается вправо.
- Мышь вверх: камера опускается к спине персонажа.
- Мышь вниз: камера поднимается над персонажем.
- Без ПКМ камера не двигается (CAM-03).

Примечание тестировщика: формулировка «камера поворачивается влево» понимается как «камера уходит влево вокруг персонажа» (как в записях 18.11); если имелось в виду, что изображение сдвигается влево, знак yaw меняется на обратный.
