Раньше: **на живой игре не проверен** (аудиту было запрещено подключаться к порту 13000 и трогать Unity). Первый запуск делать только с `--check`, потом `--dry-run`, потом боевой.

## Как вызывать
```
Test_Ai\scripts\sdk_smoke\.venv\Scripts\python.exe Test_Ai\scripts\play_control\restart_play.py --check
Test_Ai\scripts\sdk_smoke\.venv\Scripts\python.exe Test_Ai\scripts\play_control\restart_play.py --restore-save
```
- `--check` / `--dry-run`: только предусловия и снимок (frameCount, realtimeSinceStartup, consoleFlags, сцены). Stop/Play не вызываются.
- `--restore-save`: после остановки Play и ДО нового запуска возвращает `save.chop` из копии `save_backup\20261122_122526` (в этот момент игра не идёт и файл не перепишет).
- Журнал последнего запуска: `restart_play_last.json`.

## Как работает
1. Stop: `UnityEditor.EditorApplication.isPlaying = false` через AltTester (`set_static_property`). Запасной Stop: Ctrl+P.
2. Ждёт закрытия порта 13000.
3. Start: окно Unity выводится на передний план (AttachThreadInput + SetForegroundWindow), шлётся Ctrl+P (`keybd_event`). Мышь и computer use не используются. Если окно не стало активным, клавиша НЕ отправляется.
4. Ждёт AltTester и сцену MainMenu (до 120 с), проверяет, что `frameCount` меньше 3000 и меньше прежнего.

## Предусловия
- Один Unity.exe с главным окном; Play идёт; AltTester отвечает на 13000.
- Error Pause выключена (`consoleFlags` 7683, бит 4 = 0). Иначе код 2.
- Окно Unity может быть свёрнуто: скрипт его восстановит (SW_RESTORE) на время нажатия. Окно само сворачивается через ≈5 с (7b); это на скрипт не влияет, но следующий прогон начинать с `guard.restore_window`.
- `save.chop`: Stop сам его перезаписывает; используйте `--restore-save`.
- `autoSyncTransforms`: сбрасывается вместе с Play (по умолчанию False), возвращать не нужно.

## Известные ограничения и риски (не проверено)
- Запуск Play возможен ТОЛЬКО клавишей: после Stop AltTester в игре нет, из него Play не включить. Планировать запуск до остановки (delayCall, playModeStateChanged) нельзя: SDK не передаёт делегаты.
- Ctrl+P работает, только если окно Unity в фокусе и фокус не в текстовом поле. Другое окно в фокусе в момент нажатия может получить клавишу: скрипт проверяет `GetForegroundWindow` перед отправкой.
- Раньше система безопасности блокировала отправку Ctrl+Shift+P из PowerShell (run2). Для Ctrl+P может понадобиться разрешение владельца.
- Если на старте открыта не сцена Initialization/MainMenu, Play может начаться не с главного меню (код 5).
- Домен-релоад и «Enter Play Mode Options» не менялись (это настройки проекта).
